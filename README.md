# security-skills · 原创中文安全攻防技能

> 为 ZCode（等支持 skills 机制的 AI agent）编写的原创中文安全技能。内容源自 64+ 份国产实战资料（京东 JSRC 安全小课堂 93 份、绿盟护网培训 19 份）、620 条 bug bounty writeup 与开源方法论项目的消化提炼——**不是搬运**，是按 agent 技能规范重新组织的结构化知识库。

## 技能清单

### hw-hunter — 护网红蓝双视角

GitHub 上罕见的 HW/HVV 专项技能，一张卡片同时覆盖攻击与防守两侧：

- **红队**：护网计分规则（提交漏洞不得分，权限/数据才得分）、12 类攻击手法×蓝队检测对照表、检测三角降噪主线、TAC 沙箱检测链规避、免杀要点
- **蓝队**：备战自查清单（资产梳理 SOP/弱口令窗口/加固参数册）、各类攻击判定公式（Webshell/挖矿/永恒之蓝/失陷）、国产安全产品线职责表（NTI/TSA/IPS/WAF/ESPC/TAC/UTS-TAM）、应急三要素法、蓝队反制
- **面试**：考察逻辑三条件 + 红蓝高频题与答案要点 + 报菜名清单

### cnvd-cnnvd — 国产漏洞报送

CNVD/CNNVD/补天报送全流程，含正式文档里查不到的实操细则：

- **平台**：平台现状与新手排序、CNVD 证书细则（注册资金 5000w 门槛、10 案例结构 3+7、白盒不混黑盒纪律）、案例凑数流程
- **报告**：五要素、三段式模板、定级公式、危害提升链（单点低危→Critical）
- **合规**：《网络产品安全漏洞管理规定》条款表（未公开漏洞不出境/重大活动禁发布）、行为红线十条、刑法 285/286 衔接、溯源自保

## 为什么原创

- 市面 agent 技能库（英文为主）只覆盖通用方法论，没有中文护网生态与国产报送路径
- 蓝队视角（检测逻辑→反推红队降噪）在技能形态里几乎空白
- 国产平台细则（CNVD 门槛/案例结构/合规条款）散落在口口相传，未见于任何公开技能库

## 安装

```bash
# ZCode
cp -r hw-hunter cnvd-cnnvd ~/.zcode/skills/
# 其他支持 skills 的 agent：把目录放入对应 skills 路径即可
```

每个技能 = 一个 `SKILL.md` 路由器（常驻元数据约 100 token）+ `references/` 按需加载的深度文件。
